Google 登入設定
照著複製，剩下的交給網站。

登入介面與清單同步程式已準備。你只需要在 Google 建立一組網站憑證，將兩個值貼入 Vercel。這張小抄不會收集或儲存憑證。

① 開啟 Google Cloud② 開啟 Vercel 設定

1. 建立 Google OAuth Client

選擇網站專案 → Google Auth Platform → Clients → Create client。類型選 Web application。若先要求 Branding / Audience，填寫網站名稱與你的聯絡信箱，Audience 選 External。

名稱Chullin Market Watch
Authorized JavaScript originshttps://chullin.tw
Authorized redirect URIshttps://chullin.tw/api/auth/callback/google
只需基本帳號資料，不要加入 Drive 或 Gmail 存取權限。建立成功後，保留顯示 Client ID 與 Client Secret 的視窗。

2. 將兩個值貼到 Vercel

每個變數的 Environment 都選 Production，類型選 Secret / Sensitive。值直接從 Google 視窗複製到 Vercel。

貼入 Google 的 Client IDAUTH_GOOGLE_ID
貼入 Google 的 Client SecretAUTH_GOOGLE_SECRET

AUTH_SECRET 與 AUTH_URL 已設定，不需要你複製。

請勿把密鑰貼到聊天或 Git。既有 Redis 資料庫會沿用。

3. 告訴我「設定好了」

我會檢查變數名稱是否齊全，推送並部署登入功能，再陪你完成第一次 Google 登入。實際登入後才能確認第二部裝置能載入同一份 2330 清單。

若 Google 顯示 Testing，先在 Audience → Test users 加入要測試的帳號。要開放大家使用，再完成正式發布。
